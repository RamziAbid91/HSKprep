# HSK Prep

A SwiftUI iPhone/iPad app for beginners preparing for HSK 1–3.

**Home** – daily goal, today's plan, streak · **Learn** – vocabulary + grammar lessons · **Practice** – flashcards (spaced repetition), multiple choice, typing, listening, mistake review · **Exams** – timed listening + reading practice exams with explanations · **Progress** – readiness, accuracy, weak words, study calendar

## Run it (Mac with Xcode 15+)

```bash
brew install xcodegen
cd HSKPrep
xcodegen generate
open HSKPrep.xcodeproj
```

Choose an iPhone simulator and press ▶︎. If you are upgrading from the first version and the app crashes on launch, delete it from the simulator once (the saved data format changed).
