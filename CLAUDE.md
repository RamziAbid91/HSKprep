# HSK Prep — notes for Claude Code

iOS 17+ SwiftUI + SwiftData app helping beginners prepare for HSK levels 1–3.
No third-party dependencies (Apple frameworks only: SwiftUI, SwiftData, AVFoundation, Charts).

## Navigation (5 tabs)
- **Home** (`HomeView.swift`) — red hero card (greeting, streak, goal ring), continue button, today's plan, word of the day (photo), tip of the day, stats, exam countdown. Person icon → `SettingsView` (same file, links to photo credits).
- **Learn** (`LearnView.swift`) — level banner, Tips & tricks (`Tips.swift`: study tips, tone chart, radicals), vocabulary list + word detail (photo, radical memory trick, related words), grammar lessons with tricks → `GrammarPracticeView` (sentence builder + fill-in-the-blank), mixed grammar quiz.
- **Practice** (`PracticeView.swift`) — flashcards (3D flip, `FlashcardsView.swift`), multiple choice (incl. photo questions), typing, word listening drill, tone trainer, dictation, exam-style listening/reading (`ExamPracticeView` in `ExamQuestionViews.swift`), mistake review. `QuizView(mode:)` = vocab quiz; `QuestionCard` = shared exam-style question UI.
- **Exams** (`ExamsView.swift`) — instructions → timed exam built by `ExamBuilder` (4 listening + 4 reading parts × 5 questions, structure follows the HSK 2.0 papers per level; 2 plays per recording; no feedback until submit) → section breakdown, per-question review with transcript, history.
- **Progress** (`ProgressTabView.swift`) — readiness per level, mastered/learning/new, accuracy per skill, most-missed words → revision session, study calendar.

## Data
- `Models.swift` — `Word` (bundled), SwiftData: `CardProgress` (SM-2 state), `Attempt` (every answer), `StudyDay` (daily totals), `TestResult`.
- `Services.swift` — `VocabularyStore`, `Speaker` (zh-CN TTS), `Tracker` (records attempts/time), `Stats` (streak, accuracy, mistakes, readiness), `Pinyin` (lenient matching).
- `SpacedRepetition.swift` — SM-2.
- `Grammar.swift` + `GrammarMore.swift` — 34 grammar points (HSK 1–3) with examples, common mistakes, exercises and memory tricks (`tips`, `extraTips`). Original content.
- `Photos.swift` — `PhotoStore` + `PictureView`: each picture emoji maps (Photos.json ← `tools/photo_titles.py`) to an English Wikipedia article; its lead photo (Wikimedia Commons, free licence) is fetched via the Wikipedia REST summary API, cached in Caches/photos, emoji shown as fallback. Optional offline bundle: `tools/download_photos.py` → `HSKPrep/BundledPhotos/` (folder reference in project.yml).
- `HSKPrepApp.swift` — `Theme` colours (Chinese red accent, level colours).
- `Vocabulary.json` — full HSK 2.0 lists (HSK1 151, HSK2 147, HSK3 298). Fields: id, hanzi, pinyin, english, level, emoji (picture), example/examplePinyin/exampleEnglish (hand-written for the first 120). Generated by `tools/build_vocab.py` from `tools/source/old{1,2,3}.json` (complete-hsk-vocabulary, MIT) — edit OVERRIDES / EMOJI there, then rerun.
- `ExamContent.json` — original exam-style bank: listening (picture, statement ★, dialogue, passage) and reading (reply, cloze, passageTrueFalse, passageQuestion), with pinyin + translations. Edit `tools/build_content.py` (needs `pip install pypinyin`) and rerun. Models + `ContentStore` + `ExamBuilder` live in `ExamContent.swift`.
- Recorded audio: `tools/generate_audio.py` (Azure neural TTS, key from env AZURE_SPEECH_KEY/REGION) writes `HSKPrep/Audio/<key>.mp3` + `manifest.json` (folder reference in project.yml); key = first 20 hex of SHA-256("<voice>|<text>") — keep `RecordedAudio.key` (Services.swift) in sync. If you add new spoken text, rerun the script (it resumes).
- `Speaker` (Services.swift) plays recorded audio first (toggle in Settings), else the iOS voice chosen in Settings → Voice & speed (`VoiceSettingsView`, UserDefaults keys voiceMain/voiceMale/voiceFemale/voiceRate); default = best-quality installed zh-CN voice. `Speaker.play(lines, question:)` reads dialogues with separate 男/女 voices (pitch shift if only one voice), then 问：question.

## Conventions
- Edit `project.yml` (XcodeGen), not the .xcodeproj.
- Word IDs (`<level>-<nnn>`) and grammar IDs (`g-…`) must stay stable — progress is keyed on them.
- Record every answer with `Tracker.record(...)` so accuracy and mistake review keep working.
- Syllabus is labelled HSK 2.0 in `Syllabus` (Models.swift). Never label generated questions as official.
